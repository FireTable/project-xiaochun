# `@firetable/web-runtime`

Project XiaoChun's workspace fork of `@mlc-ai/web-runtime` (`0.28.0-dev2`, upstream [`apache/tvm` `web/`](https://github.com/apache/tvm/tree/cbb1e12/web) commit `cbb1e12`), licensed under **Apache-2.0** (see [`LICENSE`](./LICENSE) and [`NOTICE`](./NOTICE)).

## Enhancements Over Upstream `0.28.0-dev2`

1. **Multi-Submodule Time-Sliced Shader Pipeline Compilation (`asyncLoadWebGPUPipelines` + `hookWebGPUModuleLoader`)**: Hooks `ffi.Module.load_from_bytes.webgpu` so hybrid Relax VM executables with multiple embedded WebGPU sub-modules (e.g. `13` custom GatedDeltaNet/sampling TIR kernels + `225` main Relax/ViT kernels in `MiniCPM-V-4.7-1B`) prebuild **all** `238` shaders asynchronously instead of stopping at `imported_modules[0]` and falling back to blocking `device.createComputePipeline` on the first turn. Replaces upstream's unbounded `Promise.all` flood with concurrency-bounded micro-batches (`DESKTOP` vs `MOBILE` presets).
2. **Valid `GPUShaderModuleCompilationHint` (`createShadeInternal`)**: Fixes `compilationHints[0].entryPoint` from hardcoded `"main"` to `finfo.name` so Dawn pre-compiles pipelines against the actual kernel entry point and `GPUPipelineLayout`.
3. **Auto-Segmented `GPUCommandEncoder` (`maxDispatchesPerEncoder`: `24` desktop / `12` mobile)**: Automatically flushes accumulated compute passes every 12–24 dispatches instead of submitting 400–1100 passes in one monolithic command buffer, allowing Metal / DX12 / Vulkan to interleave foreground 60 FPS WebGL2 frames even on 4B–8B models.
4. **Canonical-Key Mirror Failover, LPT Work-Stealing & 4-Way HTTP `Range` Giant-Shard Downloads (`artifact_cache.ts` & `runtime.ts`)**:
   - Normalizes Hugging Face (`huggingface.co` ↔ `hf-mirror.com` / custom origins) and MLC WASM (`raw.githubusercontent.com` ↔ `jsdelivr` / `ghfast`) URLs back to canonical cache keys (`toCanonicalArtifactUrl`) across Cache Storage, IndexedDB, OPFS, and CrossOriginStorage while transparently failing over across configured mirrors on CORS/network/5xx errors (`fetchArtifactWithMirrorFailover`) and deduplicating concurrent `addToCache` calls (`GLOBAL_INFLIGHT_CACHE_ADDS`);
   - Downloads tensor shards in parallel via a Largest-Processing-Time-first (LPT) work-stealing queue (`maxParallelShardDownloads = 6` desktop / `2` mobile) with live `TransformStream` byte progress;
   - Accelerates giant shards `≥ 48 MiB` (e.g. `127.5 MiB` embedding shards) on desktop using `4` concurrent HTTP `Range` (`206 Partial Content`) slices (`fetchArtifactResponseWithAcceleration`), probing slice `0` first for zero-waste `200 OK` compatibility and clean single-stream fallback.
5. **Closed-Loop Sliced Weight Streaming, Legacy `0.2.84` TVM FFI Compatibility & Bulk Allocation Scopes**: Coalesces `pushErrorScope`/`popErrorScope` across tensor shards (`fetchTensorCacheInternal`) and KV-cache allocation (`beginBulkAllocation`), streams large tensors (`50+ MB`) in `2–4 MB` chunks with closed-loop latency feedback (`syncAndAdaptUploadSlice`), removes redundant `response.clone()` copies in `ArtifactIndexedDBCache`, and preserves legacy `TVMFFIWasmFunctionRegistry` / `wasm.TVMFFIFunctionCall` compatibility alongside modern TVM `0.28` FFI exports.
6. **Device-Tier Frame Pacing Presets (`DESKTOP_WEBGPU_FRAME_PACING` / `MOBILE_WEBGPU_FRAME_PACING`)**: Exports runtime-switchable `setWebGPUFramePacing` / `getWebGPUFramePacing` and `setArtifactMirrorConfig` / `getArtifactMirrorConfig` helpers alongside clean browser/worker ESM output.
