# `@firetable/web-llm`

Project XiaoChun's workspace fork of [`@mlc-ai/web-llm`](https://github.com/mlc-ai/web-llm) (`v0.2.88`, commit `e56c954a187590c404fc19dcf9942df4f002f661`), licensed under **Apache-2.0** (see [`LICENSE`](./LICENSE)).

## Enhancements Over Upstream `0.2.88`

1. **Parallel `reload()` Handshake Pre-Warming (`MLCEngine.reloadInternal`)**: Launches `model_manifest`, speculative `mlc-chat-config.json`, speculative `tensor-cache.json`, WASM fetch + instantiation, and `detectGPUDevice()` concurrently at `t = 0`, then downloads and parses `tokenizer.json` (`11–16 MB`) in parallel (`Promise.all`) with `tvm.fetchTensorCache()`, eliminating 4–5 serial cross-ocean round-trips while deterministically disposing any native/GPU handles on abort or failure.
2. **Adaptive High-Resolution Vision `<slice>` Tiling (`computeSlicedGrid` + `getSlicedRGBTilesFromURL` + `getArtifactPrefillChunks`)**: Automatically partitions wide, tall, and HD images into `1` global `448×448` overview + `rows×cols` aspect-preserving `<slice>...</slice>` tiles (`maxSlices = 6` desktop / `2` mobile, `image_url.detail?: "auto" | "low" | "high"`), yielding between every tile's `embed_image` ViT pass and clamping slices to fit remaining `context_window_size`.
3. **Dual Legacy `0.2.84` + Modern `0.2.88` `mlc.model-package` ABI Compatibility**: Supports root-relative `/wasm/...` manifests & WASM binaries alongside remote weight URLs, and falls back gracefully when loading older `0.2.84`-compiled MLC WASMs (such as `MiniCPM5-2B-q4f16_1-MLC`) that omit `create_tir_paged_kv_cache` state/logit query exports.
4. **Roofline-Preserving Interactive Prefill Slicing (`interactivePrefillChunkSize`: `128` desktop / `64` mobile)**: Slices foreground prompt prefill (text + multimodal embeddings) into 64/128-token chunks while preserving the compiled `prefill_chunk_size` (`2048`) for KV-cache allocation and relying on `@firetable/web-runtime`'s intra-forward `maxDispatchesPerEncoder` splitting so long-context TTFT stays fast without starving 60 FPS WebGL2 rendering.
5. **Inter-Stage, Prefill & Cumulative-Budget Decode Yielding + Stream Multiplexing**: Inserts cooperative `device.sync()` + macrotask yields right after ViT vision encoding, between prefill slices (immediately disposing intermediate `chunkLogits` and consumed adapter tensors), and whenever cumulative decode GPU time reaches the slice budget, plus `streamId`-scoped `completionStreamReturn` cleanup in `WebWorkerMLCEngineHandler`.
6. **Frame Pacing & Canonical Mirror Failover Re-Exports**: Re-exports `setWebGPUFramePacing`, `getWebGPUFramePacing`, `DESKTOP_WEBGPU_FRAME_PACING`, `MOBILE_WEBGPU_FRAME_PACING`, `setArtifactMirrorConfig`, `getArtifactMirrorConfig`, `toCanonicalArtifactUrl`, `resolveArtifactMirrorUrls`, `fetchArtifactWithMirrorFailover`, and `fetchArtifactResponseWithAcceleration` from `@mlc-ai/web-runtime`.
