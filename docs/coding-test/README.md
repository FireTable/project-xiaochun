# Project XiaoChun · 4 章节视频录播与交互演播台 (Coding Test)

> 本目录为 Project XiaoChun 面向 72 小时互动挑战赛视频录制与现场汇报所构建的独立演播台套件 (`docs/coding-test/chalkboard.html`)。

---

## 📌 概述与定位

`chalkboard.html` 是一个高度集成的**纯前端视频演播与录屏演播室**：
1. **左侧大屏黑板（Chalkboard）**：高质感复古木框黑板，支持手绘粉笔字、板书自动排版、箭头、流程框、重点圈与撤销/存图；
2. **右侧 3D 伴侣嵌入（XiaoChun 3D）**：通过 `@firetable/project-xiaochun` 双向通信协议（`/embed` + `MessageChannel`）无缝融入黑板，透明无边框无多余按钮；
3. **中央 16:9 电影演示大屏**：预留标准 16:9 剪辑安全框，支持拖入本地 MP4 实机录屏全屏播放，演播时小蠢讲完自动放大展示并在 3 秒后缩回黑板；
4. **4 章节一键全流程自动演播**：按序连贯演播 4 个核心章节，小蠢同步朗读台词（TTS）、执行匹配动作连招与表情，全程约 50 秒。

## ⌨️ 快捷键与录屏辅助

演播台内置录屏模式，录屏时可一键净化界面：

| 快捷键 | 功能说明 |
| :--- | :--- |
| **`H`** | **一键隐藏/恢复全部操作栏**（隐藏顶部导播总控条与底部粉笔槽，纯净黑板用于录像） |
| **`1` ~ `4`** | 分别跳转演播第 1、2、3、4 章节 |
| **`Space` (空格)** | **一键启动全流程连续自动录制**（自动连续演练 4 个章节，约 50 秒） |
| **`Cmd + Z` / `Ctrl + Z`** | 撤销上一步黑板笔迹（支持 30 步历史记录） |

## 🛠️ 技术实现细节

1. **双向协议桥（`XC_PROTOCOL_VERSION = 1`）**：
   - 载入 `/embed?scene=transparent&transparent=1&host=...&heavy=eager`；
   - 监听 `xc.ready` 握手并传递 `channel.port2`，双向通信端口单例化防 neutered；
   - 严格追踪 `xc.utterance phase: 'end'` 事件，台词讲完后才触发下一步演示。
2. **黑板手绘引擎**：
   - 多孔质感粉笔算法（微细噪点与半透明粒子堆叠）；
   - 支持白/黄/粉/青/绿/橙 6 色与 3 级粗细；
   - 绘制时动态锁定 iframe 鼠标事件，画笔划过无阻断。
3. **16:9 实机演示框**：
   - 正常状态嵌入黑板中央偏左，全屏状态拓展为 `100vw x calc(100vh - 36px)`；
   - 支持拖入本地 MP4 / WebM 视频直接全屏播放；
   - 内置安全角线（Safe Corner Markers），为视频后期剪辑对齐提供像素级参考。
